# Contributors

Thank you to everyone who has contributed to **Soroban Migration Simulator (SMS)**! Your work helps make Soroban contract migrations safer for the entire Stellar ecosystem.

---

## How to Add Yourself

1. Fork the repo and create a branch
2. Copy the template below and fill in your details
3. Add your `<div>` block inside the `<!-- CONTRIBUTORS-START -->` section (above the `<!-- Add your <div> above this line -->` comment)
4. Open a PR with the title: `docs: add [your-name] to contributors`

### Template

```html
<div style="display:inline-block;width:130px;vertical-align:top;text-align:center;margin:8px">
  <a href="https://github.com/YOUR_GITHUB_USERNAME">
    <img src="https://github.com/YOUR_GITHUB_USERNAME.png" width="80" style="border-radius:50%" alt="Your Name" />
    <br />
    <sub><b>Your Name</b></sub>
  </a>
  <br />
  <a href="https://github.com/YOUR_GITHUB_USERNAME"><img src="https://img.shields.io/badge/-GitHub-181717?logo=github&logoColor=white&style=flat-square" alt="GitHub" /></a>
  <br />
  <sub>Role — Crate or area of contribution</sub>
</div>
```

**Replace** `YOUR_GITHUB_USERNAME`, `Your Name`, and the role/contribution line.

### Roles

| Role | Description |
|------|-------------|
| **Maintainer** | Core project maintainer |
| **Contributor** | Code contributions (features, fixes, tests) |
| **Researcher** | Research, documentation, or analysis contributions |

### Contribution Areas

List the crates or areas you contributed to (comma-separated). Examples:

```
<sub>Contributor — migration-engine, state-engine</sub>
<sub>Researcher — architecture docs, migration-guide</sub>
<sub>Contributor — analyzer, wasm-diff</sub>
```
